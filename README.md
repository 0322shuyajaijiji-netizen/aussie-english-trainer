# Aussie English Trainer

**公開準備済み・GitHub Pagesは未公開です。** 公開するときの最後の操作は [PUBLISHING.md](PUBLISHING.md) を参照してください。

オーストラリア研修に参加する高校生向けの、無料・ログイン不要の英会話Webアプリです。既存の129フレーズ・日本語訳・全会話例を変更せず収録しています。

## 費用と構成

HTML / CSS / JavaScriptだけの静的アプリです。**有料API、生成AI、データベース、APIキー、アカウント登録、外部ライブラリ、トラッカーは不要**です。GitHubの無料プランの公開リポジトリ＋GitHub Pagesの標準URLで運用できます。独自ドメインは不要です。ホスティングの無料枠・利用規約に従ってください。通信費・端末費用は別途です。

音声合成・音声認識・録音はブラウザの機能を使います。アプリから従量課金サービスを呼び出すことはありません。ブラウザの音声認識サービスはオンライン接続が必要な場合があり、常時・全機種での提供を保証するものではありません。

## 起動方法

1. ZIPを展開し、`aussie-english-trainer` フォルダを開きます。
2. Python 3があるPCなら、このフォルダで次を実行します（追加インストール不要）。

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

   Windowsでは `python -m http.server 8000 --bind 127.0.0.1` も利用できます。
3. 同じPCで `http://localhost:8000` を開きます。終了はターミナルで Ctrl+C。

`index.html` を直接開いても基本学習は使えますが、ファイルURLでの保存やマイク権限はブラウザによって異なります。録音・音声認識の確認にはlocalhostまたはHTTPSを使ってください。

スマートフォンでは、下記のGitHub PagesなどでHTTPS公開したURLを開いてください。PCのLAN内IPを使う通常のHTTP接続では、録音に必要な安全なコンテキストとして扱われません。

## GitHub Pagesで無料公開

1. GitHubに無料アカウントを作成し、公開（Public）リポジトリを用意します。
2. このフォルダのファイルを `main` ブランチのルートにアップロードします。最低限必要なのは以下です。

   ```text
   index.html
   styles.css
   app.js
   core.js
   scenarios.js
   phrases.js
   phrases.json
   assets/mark.svg
   assets/australia.svg
   .nojekyll
   ```

3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選びます。
4. Branchを **main**、フォルダを **/(root)** にして保存します。
5. 表示された `https://ユーザー名.github.io/リポジトリ名/` を開きます。HTTPSのまま利用してください。

すべて相対パスなので、リポジトリ名がURLに含まれるGitHub Pagesでも使えます。ビルド・Actions・サーバー・環境変数の設定は不要です。GitHub Pagesへの公開は実行していません。別途、Sitesで所有者のみ閲覧可能な確認用サイトを用意しています。

## 学習の使い方

- **フレーズ**：英語・日本語・番号で検索。7カテゴリーまたは苦手だけに絞れます。英文・日本語訳は独立して非表示にできます。英語非表示は会話例と一覧にも反映します。「覚えた！」で学習済み、☆で苦手に登録。
- **お手本音声**：en-AUの音声を優先し、なければ他の英語音声を使用します。「発音練習」で選択された音声を表示します。英語音声が一つもなければOS側で追加してください。音声機能がないブラウザでは英文を読んで練習できます。
- **発音練習**：録音→停止→再生で聞き直します（最長60秒）。別途「マイクで英文を認識」を実行すると英文が表示され、お手本との一致・欠落・追加を色と記号で確認できます。手入力でも照合可能です。録音と認識は同時には実行しません。
- **暗記チェック**：「話して答える」で回答します。日本語→英語はen-AU、英語→意味はja-JPで音声認識します。英語は単語一致度85%以上、日本語の意味は句読点・空白を除いた解答例との一致で正解を記録し、**GOOD!** のポップアップを表示します。音声認識は発音採点ではありません。認識が違う場合はすぐ誤答にせず、再挑戦または解答例を見て自己確認できます。認識非対応でも声に出して解答を確認する学習は継続できます。誤答を最優先、次に苦手・未挑戦を優先します。同じ問題の二重回答は記録しません。次問では直前の1問を避けます。日本語の言い換えは自動判定できないため、自己確認してください。
- **会話練習**：教材ロールプレイは全129会話から選択し、A/Bどちらの役も担当できます。学校での会話は「あいさつ」などに含まれます。会話全文は最初から表示され、現在の番を枠で示します。各行の再生ボタンで聞き直せます。自分の番は認識で照合するか、声に出して次へ進めます。追加の分岐練習はカフェ・空港・学校・街の4場面。選択によって相手の返答が変わります。最初に相手の音声ボタンを押し、自分の返答を声に出してから選択します。音声が使えなくてもボタンで先に進めます。生成AI・自由会話は搭載していません。
- **学習記録**：学習済み数、暗記正答率、苦手、学習回数、セッション数、学習日数、カテゴリー別進捗、達成バッジを確認できます。学習回数は、お手本再生・学習済み登録・英文照合・暗記回答・会話完了などの操作数です。正答率は暗記チェックの音声照合と自己確認の合計で算出します。発音点数ではありません。

## 発音の採点と単語一致度の違い

このアプリは**発音の正確さを採点しません**。「単語一致度」は、音声認識で得られた英文（または手入力）と教材の英文の単語・語順を比較する指標です。

句読点・大文字小文字・曲がったアポストロフィを正規化し、最長共通部分列（LCS）で対応づけます。音声照合では代表的な短縮形を展開し、教材の `/` と括弧による選択表現から最も一致する候補を使います。表示される単語も同じ正規化後の候補です。一致度は `200 × 一致単語数 ÷（お手本の単語数＋入力の単語数）` です。✓緑は一致、△オレンジは欠落、△赤は異なる／追加された単語です。

認識サービスの誤り、雑音、言い換え、短縮形や選択表現の複雑な組み合わせなどによって、伝わる発話でも低い数値になることがあります。お手本と録音の聞き比べに使い、評価・成績判定には使用しないでください。

## ブラウザとマイク

| 機能 | 必要なもの | 利用できないとき |
| --- | --- | --- |
| お手本再生 | SpeechSynthesisとOSの英語音声 | 英文を読む。OSで英語音声を追加 |
| 録音・再生 | HTTPS/localhost、getUserMedia、MediaRecorder、マイク権限 | ブラウザのサイト設定、マイク接続を確認。手入力も利用可 |
| 音声認識 | SpeechRecognition / webkitSpeechRecognition、マイク権限、サービス接続 | 録音・再生、手入力、声に出して次へ進む |
| 学習記録 | localStorage | 一時的に学習可能。JSONでバックアップ |

- Chrome / EdgeのPC版・Android版、SafariのmacOS/iOS版などでも、OS・バージョン・管理ポリシーによって音声機能の可否が異なります。Firefoxなど音声認識に対応しないブラウザでも、録音APIがあれば録音再生を使えます。対応はアプリ内で機能検出します。特定のブラウザでの音声認識動作を保証するものではありません。
- マイクを拒否したときはURL横などのサイト設定から許可し、再試行してください。学校管理の端末やネットワークでは機能が制限される場合があります。
- 録音データはメモリ内だけに保持し、画面移動・ページ終了・タブの非表示時に消去します。マイクのトラックも停止します。認識と録音は独立しており、認識非対応でも録音は行えます。
- 音声認識はブラウザ提供元のオンラインサービスへ音声を送信する場合があります。アプリ自身は録音のアップロード機能を持ちません。音声合成も端末・選択音声によってオンライン処理の場合があります。完全オフラインの音声機能は保証しません。
- 本番のブラウザ実機テストは未実施です。下記 `TEST_REPORT.md` の公開前確認表を使ってください。

## 記録・バックアップ

localStorageキーは旧版と同じ `aussie-english-v1` です。同じオリジンで更新すれば学習済み・苦手（旧お気に入り）・フレーズごとの学習回数を引き継ぎます。旧版が持たなかった正答率・日別操作数などは新しい学習から記録します。URL・ブラウザ・端末が変わる場合は自動同期されないため、旧版のJSON保存→新版の復元を利用してください。

学習記録画面の「JSONで保存」でバックアップ、「バックアップを復元」で読み込みます。復元時は置換の確認を行い、不正な値・未知のIDを除去します。2MBを超えるファイルは受け付けません。録音はバックアップに含まれません。共有端末では同一ブラウザの利用者で記録が共有されます。

## 教材の編集とテスト（開発者向け）

実行自体にNode.jsは不要です。教材更新と自動テストにはNode.js 22以降を使用してください。パッケージインストールは不要です。

```sh
node scripts/build-data.mjs
node --test tests/app.test.mjs
node scripts/check-release.mjs
node --check app.js
```

`phrases.json` が教材の編集元、`phrases.js` は直接ファイルを開く用途にも対応するための生成物です。教材を編集したら生成スクリプトを実行し、両ファイルを公開します。英文を変更する際は `CONTENT_CHANGELOG.md` に旧文・新文・理由を記録してください。元の4ファイルを `original/` にそのまま保存しています。追加分岐は `scenarios.js` に分離しています。

```text
index.html            画面の骨組み
styles.css            モバイル優先のレスポンシブUI
app.js                学習画面・ブラウザ音声・保存処理
core.js               単語照合・復習順・保存データ検証
phrases.json          129フレーズの教材ソース（原文保持）
phrases.js            自動生成したブラウザ配信用データ
scenarios.js          4場面の追加分岐
assets/mark.svg       アプリアイコン（自作SVG）
assets/australia.svg  豪州の地図・海・オペラハウスのイラスト（自作SVG）
scripts/              教材データ生成
tests/               Node.jsによる自動テスト（DOM・音声APIのスタブ）
original/             元プロジェクトの全ファイルを保存
ANALYSIS.md           既存コードの分析と改善対応
CONTENT_CHANGELOG.md  教材変更履歴
TEST_REPORT.md        自動テスト結果と実機未確認項目
```

アプリの素材はローカルの自作SVGとシステムフォントだけです。教材の利用・公開権限は元教材の条件を引き継ぎます。
