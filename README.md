# Aussie English Trainer

**公開URL： https://english-conversation-six.vercel.app/**

2026-11-20：Vercelの本番公開を確認済みです。GitHub Pagesの停止は管理者による設定操作待ちです。

公開設定・更新方法は [PUBLISHING.md](PUBLISHING.md) を参照してください。

オーストラリア研修に参加する高校生向けの、無料・ログイン不要の英会話Webアプリです。既存129フレーズ・日本語訳・全会話例を保持し、研修向けの94フレーズを追加した、全223フレーズ・13シチュエーションの教材です。

## 費用と構成

HTML / CSS / JavaScriptだけの静的アプリです。**有料API、生成AI、データベース、APIキー、アカウント登録、外部ライブラリ、トラッカーは不要**です。GitHubの無料プランの公開リポジトリ＋GitHub Pagesの標準URLで運用できます。独自ドメインは不要です。ホスティングの無料枠・利用規約に従ってください。通信費・端末費用は別途です。

音声合成・音声認識はブラウザの機能を使います。録音・録音再生の機能はありません。アプリから従量課金サービスを呼び出すことはありません。ブラウザの音声認識サービスはオンライン接続が必要な場合があり、常時・全機種での提供を保証するものではありません。

## 起動方法

1. ZIPを展開し、`aussie-english-trainer` フォルダを開きます。
2. Python 3があるPCなら、このフォルダで次を実行します（追加インストール不要）。

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

   Windowsでは `python -m http.server 8000 --bind 127.0.0.1` も利用できます。
3. 同じPCで `http://localhost:8000` を開きます。終了はターミナルで Ctrl+C。

`index.html` を直接開いても基本学習は使えますが、ファイルURLでの保存やマイク権限はブラウザによって異なります。音声認識の確認にはlocalhostまたはHTTPSを使ってください。

スマートフォンでは、下記のGitHub PagesなどでHTTPS公開したURLを開いてください。PCのLAN内IPを使う通常のHTTP接続では、音声入力に必要な安全なコンテキストとして扱われません。

## GitHub Pagesで無料公開

1. GitHubに無料アカウントを作成し、公開（Public）リポジトリを用意します。
2. このフォルダのファイルを `main` ブランチのルートにアップロードします。最低限必要なのは以下です。

   ```text
   index.html
   styles.css
   app.js
   core.js

   feedback.js
   conversation.js
   scenarios.js
   phrases.js
   phrases.json
   assets/mark.svg
   assets/australia.svg
   .nojekyll
   ```

3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選びます。
4. Branchを **main**、フォルダを **/(root)** にして保存します。
5. 表示された `https://ユーザー名.github.io/リポジトリ名/` を開きます。HTTPSのまま利用してください。

すべて相対パスなので、リポジトリ名がURLに含まれるGitHub Pagesでも使えます。ビルド・Actions・サーバー・環境変数の設定は不要です。GitHub Pagesで公開済みです。生徒への共有は上記の公開URLを使用してください。

## Vercelで公開する場合

Vercelでも静的サイトとして公開できます。GitHubリポジトリをインポートし、Framework Presetは **Other**、Root Directoryは **リポジトリ直下（./）**、Build Commandは `node scripts/build-vercel.mjs`、Output Directoryは `dist` にします。Install Commandは空欄、環境変数は不要です。`vercel.json` に設定を追加済みです。

配信用の15ファイルだけを `dist/` にコピーし、JS/CSS/教材は変換しません。元のルート配置を維持しているため、GitHub Pagesも引き続き使えます。Vercelで本番公開しています。手順・無料プランの条件・学習記録の移行は [VERCEL.md](VERCEL.md) を参照してください。

## 学習の使い方

フレーズ・発音・暗記・会話は、どれも最初にシチュエーションを選びます。選択した場面の教材だけが表示・出題され、「シチュエーションを選び直す」で戻れます。「すべてのフレーズ」も選択できます。発音の前後移動・正解後の自動移動、暗記の誤答優先復習も同じ場面の中で行います。会話の追加分岐は対応する場面がある場合だけ表示します。

- **フレーズ**：最初に13のシチュエーションから選び、その場面のフレーズを表示します。「すべてのフレーズ」「苦手を復習」も選べます。選択後は苦手フレーズだけに絞り込めます。英文・日本語訳は独立して非表示にできます。英語非表示は会話例と一覧にも反映します。「覚えた！」で学習済み、☆で苦手に登録。
- **お手本音声**：en-AUの音声を優先し、なければ他の英語音声を使用します。「発音練習」で選択された音声を表示します。英語音声が一つもなければOS側で追加してください。音声機能がないブラウザでは英文を読んで練習できます。
- **発音練習**：お手本を聞いて「話してチェック」を押します。「話してください」と出たら話します。話し終わりを自動検出して照合します。お手本全体と一致すれば○と正解音、不一致なら×と再挑戦音を表示します。約1.1秒で表示は自動消去し、正解時は次のフレーズへ進みます。手入力は照合のみで○／×や効果音は出しません。録音・聞き直し機能は削除しました。
- **暗記チェック**：「話して答える」で回答します。日本語を見て英語で答える一方向の形式で、en-AUを使って音声認識します。英語は表記差を正規化した単語一致度100%（フレーズ全体の一致）で正解を記録し、**○と正解音**を表示して約1.1秒後に次問へ進みます。不一致なら**×と再挑戦音**を表示し、同じ問題で再挑戦できます。自己確認だけで正解にした場合は○／×や効果音は出さず、音声照合と区別します。音声認識は発音採点ではありません。認識が違う場合はすぐ誤答にせず、再挑戦または解答例を見て自己確認できます。認識非対応でも声に出して解答を確認する学習は継続できます。誤答を最優先、次に苦手・未挑戦を優先します。同じ問題の二重回答は記録しません。次問では直前の1問を避けます。
- **会話練習**：シチュエーションと自分の役を選び、「スタート」を一度押すと自動で進みます。自分がA役なら即座に聞き取り、B役なら相手の音声終了後に聞き取りを始めます。お手本全文と一致すれば○と正解音のあと次の番へ、不一致なら×のあと同じ番で自動的に聞き直します。練習対象の英文と日本語訳を冒頭に表示し、その下で会話全文を表示します。練習画面内の場面・会話の選択欄はなく、場面の変更は「シチュエーションを選び直す」、教材の移動は完了時の「次へ」で行います。スタート・一時停止・再開は会話文の上に配置しています。「一時停止」「再開」で続きから再開できます。「Extra Practice」にあるカフェ・空港・学校・街の追加分岐も、相手音声→音声で返答→選択した返答の分岐へ、という自動進行に対応します。最後の相手音声が終わるまで待ち、**Good on ya!** と上昇するファンファーレで完了を祝います。完了時の「次へ」で、選んだシチュエーション内の次の教材会話を表示します。最後の教材の次は同じ場面の先頭に戻ります。追加分岐の完了後も「次へ」で次の教材フレーズへ移れます。新しい会話はスタートで開始します。認識結果の不一致は発音品質の誤りと同義ではありません。教材ロールプレイの開始前・一時停止中は、各行の音声も聞けます。
- **ホームの学習記録**：学習済み数、暗記正答率、苦手、学習回数、セッション数、学習日数、カテゴリー別進捗、達成バッジを確認できます。学習回数は、お手本再生・学習済み登録・英文照合・暗記回答・会話完了などの操作数です。正答率は暗記チェックの音声照合と自己確認の合計で算出します。発音点数ではありません。

## 発音の採点と単語一致度の違い

このアプリは**発音の正確さを採点しません**。「単語一致度」は、音声認識で得られた英文（または手入力）と教材の英文の単語・語順を比較する指標です。

句読点・大文字小文字・曲がったアポストロフィを正規化し、最長共通部分列（LCS）で対応づけます。音声照合では代表的な短縮形を展開し、教材の `/` と括弧による選択表現から最も一致する候補を使います。表示される単語も同じ正規化後の候補です。一致度は `200 × 一致単語数 ÷（お手本の単語数＋入力の単語数）` です。✓緑は一致、△オレンジは欠落、△赤は異なる／追加された単語です。

認識サービスの誤り、雑音、言い換え、短縮形や選択表現の複雑な組み合わせなどによって、伝わる発話でも低い数値になることがあります。認識された文字列の確認に使い、評価・成績判定には使用しないでください。

## ブラウザとマイク

| 機能 | 必要なもの | 利用できないとき |
| --- | --- | --- |
| お手本再生 | SpeechSynthesisとOSの英語音声 | 英文を読む。OSで英語音声を追加 |
| 音声認識 | SpeechRecognition / webkitSpeechRecognition、マイク権限、サービス接続 | 手入力、声に出して自己確認 |
| 学習記録 | localStorage | 一時的に学習可能。JSONでバックアップ |

- Chrome / EdgeのPC版・Android版、SafariのmacOS/iOS版などでも、OS・バージョン・管理ポリシーによって音声機能の可否が異なります。Firefoxなど音声認識に対応しないブラウザでは、手入力・声に出して自己確認する方法で学習できます。対応はアプリ内で機能検出します。特定のブラウザでの音声認識動作を保証するものではありません。
- マイクを拒否したときはURL横などのサイト設定から許可し、再試行してください。学校管理の端末やネットワークでは機能が制限される場合があります。
- 音声入力は発音・暗記・教材会話・分岐会話で共通です。初回の許可待ちと聞き取り中を区別し、途中結果を表示します。発話終了イベント、または認識文字の更新停止から約2秒で発話終了を検出します。手動終了ボタンはありません。自動検出時も最終結果を待って照合します。画面移動・タブ非表示では中断し、遅れた結果を破棄します。
- en-AUの認識が言語非対応になった場合、次のマイク操作からen-USへ切り替えます。複数の認識候補があれば実際に返された候補の中から教材に最も一致するものを採用します。
- アプリ内ブラウザではなくChrome・Edge・Safariで公開URLを直接開き、サイト設定でマイクを許可してください。無音・権限拒否・通信エラー・マイク競合は画面内に説明します。機種・ブラウザ・管理ポリシーによる制限までアプリ側で解除することはできません。
- 音声認識はブラウザ提供元のオンラインサービスへ音声を送信する場合があります。アプリ自身には音声の録音・保存・アップロード機能はありません。音声合成も選択音声によってオンライン処理の場合があります。完全オフラインの音声機能は保証しません。
- 本番のブラウザ実機テストは未実施です。下記 `TEST_REPORT.md` の公開前確認表を使ってください。

## 記録・バックアップ

localStorageキーは旧版と同じ `aussie-english-v1` です。同じオリジンで更新すれば学習済み・苦手（旧お気に入り）・フレーズごとの学習回数を引き継ぎます。旧版が持たなかった正答率・日別操作数などは新しい学習から記録します。URL・ブラウザ・端末が変わる場合は自動同期されないため、旧版のJSON保存→新版の復元を利用してください。

ホームの「JSONで保存」でバックアップ、「バックアップを復元」で読み込みます。復元時は置換の確認を行い、不正な値・未知のIDを除去します。2MBを超えるファイルは受け付けません。音声データは保存しません。共有端末では同一ブラウザの利用者で記録が共有されます。

## 教材の編集とテスト（開発者向け）

実行自体にNode.jsは不要です。教材更新と自動テストにはNode.js 22以降を使用してください。パッケージインストールは不要です。

```sh
node scripts/build-data.mjs
node scripts/build-translations.mjs
node --test tests/*.test.mjs
node scripts/check-release.mjs
node --check app.js
```

`phrases.json` が教材の編集元、`phrases.js` は直接ファイルを開く用途にも対応するための生成物です。教材を編集したら生成スクリプトを実行し、両ファイルを公開します。英文を変更する際は `CONTENT_CHANGELOG.md` に旧文・新文・理由を記録してください。元の4ファイルを `original/` にそのまま保存しています。追加分岐は `scenarios.js` に分離しています。

```text

styles.css            モバイル優先のレスポンシブUI
app.js                学習画面・音声UI・保存処理

feedback.js           非モーダルの○／×表示・無料効果音・自動遷移
core.js               単語照合・復習順・保存データ検証
```

アプリの素材はローカルの自作SVGとシステムフォントだけです。教材の利用・公開権限は元教材の条件を引き継ぎます。

## 判定表示と効果音

○／×は認識された文字列とお手本の一致を示し、発音品質を採点するものではありません。表示は操作を遮らず自動で消えます。「つづける」「話し終わった」ボタンはありません。効果音はWeb Audioで生成し、外部音源・有料APIを使いません。最初のマイク操作で音声出力を準備します。端末が消音中、または音声再生を制限している場合も○／×の表示と自動遷移は動作します。権限拒否・無音・通信エラーは誤答として×を出さず、対処方法を表示します。

## 会話の自動進行とブラウザ制限

相手の読み上げ中はマイクを開始せず、読み上げの終了イベント後に短い間隔を空けて聞き取りに切り替えます。一時停止・画面移動・会話の変更は音声とマイクを停止し、古いイベントで進まないようにします。音声認識の権限拒否・無音・通信エラー・音声再生失敗の場合は、その番で一時停止します。設定を確認して「再開」してください。一部のブラウザでは自動的なマイク開始が制限されるため、端末によっては再開操作が必要になります。アプリからブラウザの制限を解除することはできません。

完了時の文字・ファンファーレは無料のWeb Audioで生成します。消音や再生制限がある端末でも完了文字は表示します。
