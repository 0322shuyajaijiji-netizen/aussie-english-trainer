# Aussie English Trainer（完全無料・試作版）

## 使い方
1. `index.html` をChromeまたはEdgeで開くと、フレーズ学習・音声再生・暗記チェック・教材ロールプレイが使えます。
2. 録音と音声認識はブラウザ・OS・権限によって制限されます。実運用ではHTTPSで公開してください。
3. GitHub Pagesに `index.html` と `phrases.js` を置けば静的サイトとして公開できます。公開前に学校の教材公開許可を確認してください。

## 機能と制約
- Word教材の129フレーズ、会話例を収録。`phrases.json` が編集用データです。
- TTSはブラウザ搭載音声。en-AUが端末にない場合は別の英語音声を利用します。
- 音声認識はSpeechRecognition対応ブラウザのみ。処理にブラウザ提供元のオンラインサービスが使われることがあります。オフライン動作は保証しません。
- 「単語一致度」は発音品質の採点ではありません。録音は端末のメモリ内で再生し、学習記録に保存しません。
- 会話練習は教材に基づく固定ロールプレイです。生成AIによる自由会話は搭載していません。
- 学習記録はlocalStorage保存。端末間同期なし。バックアップJSON出力/復元あり。
- 教材中の表現は原文を優先しています。授業公開前に英文校閲を推奨します。

## Codexに渡す次の開発指示
- 既存の静的Webアプリの全機能を維持し、モバイル操作とアクセシビリティを改善する。
- `phrases.json` を唯一の教材ソースとして、シナリオ分岐を追加する。自由会話と誤認させない表示にする。
- マイク権限・録音・音声認識の失敗時に入力モードへ切り替える。
- 日本語訳・会話例・カテゴリーの修正を容易にする。
- 有料API、外部ログイン、サーバー、トラッカーを導入しない。
